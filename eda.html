Purpose

This Quarto document explores the NBA shot data in a static way before it goes into the Shiny app. Everything here (the contingency tables, grouped numeric summaries, and plots) is something the app’s Data Exploration tab will let the user recreate on a subset of their choosing.

Data

The data come from the NBA Play-by-Play Data set on Kaggle, which records every play of every game scraped from Basketball-Reference. data_prep.R reduces the five full seasons from 2015-16 through 2019-20 to one row per field-goal attempt, keeps the useful columns, and adds derived variables such as shot value, shot kind, and the score margin from the shooting team’s point of view.

Numeric Summaries Across Categories

This helper returns summary statistics of one numeric variable at each level of one categorical variable. It takes the variable names as strings, so the same function can be reused in the app with input$... values.

Code 
summarize_numeric <- function(data, num_var, group_var) {
  data |>
    group_by(.data[[group_var]]) |>
    summarise(
      n      = n(),
      mean   = mean(.data[[num_var]], na.rm = TRUE),
      median = median(.data[[num_var]], na.rm = TRUE),
      sd     = sd(.data[[num_var]], na.rm = TRUE),
      q1     = quantile(.data[[num_var]], 0.25, na.rm = TRUE),
      q3     = quantile(.data[[num_var]], 0.75, na.rm = TRUE),
      .groups = "drop"
    ) |>
    mutate(across(where(is.double), \(x) round(x, 2)))
}

3. Histogram: shot distance by shot value

Distances beyond 40 ft are end-of-quarter heaves and are cut from the plot so the main shape is visible.

Code 
shots |>
  filter(shot_dist <= 40) |>
  ggplot(aes(x = shot_dist, fill = shot_value)) +
  geom_histogram(binwidth = 1, boundary = 0, color = "white", linewidth = 0.1) +
  scale_y_continuous(labels = comma) +
  scale_fill_manual(values = c("2-pt" = "#1d428a", "3-pt" = "#c8102e")) +
  labs(
    title = "Distribution of Shot Distance",
    subtitle = "Shots from 40 ft or closer",
    x = "Shot distance (ft)",
    y = "Attempts",
    fill = "Shot value"
  ) +
  theme_minimal()

This histogram shows the distribution of shot distance, color coded by shot value. The official NBA 3 point line is at 23 feet (and 9 inches), so any shot beyond that is a 3 point attempt. It’s interesting to see the bimodal nature of this data, where players are really prioritizing dunks/layups from a few feet away, or 3 point jump shots from around 23 to 26 feet away.

5. Scatter plot: FG% vs distance

Each point is one distance (in feet) for one shot value, sized by how many attempts came from there. Distances with fewer than 100 attempts are left out because their FG% is too noisy.

Code 
fg_by_dist <- shots |>
  filter(shot_dist <= 35) |>
  group_by(shot_dist, shot_value) |>
  summarise(attempts = n(), fg_pct = mean(made), .groups = "drop") |>
  filter(attempts >= 100)

ggplot(fg_by_dist, aes(x = shot_dist, y = fg_pct, color = shot_value)) +
  geom_point(aes(size = attempts), alpha = 0.8) +
  scale_y_continuous(labels = percent) +
  scale_size_continuous(labels = comma) +
  scale_color_manual(values = c("2-pt" = "darkblue", "3-pt" = "red")) +
  labs(
    title = "Field-Goal Percentage by Shot Distance",
    x = "Shot distance (ft)",
    y = "FG%",
    color = "Shot value",
    size = "Attempts"
  ) +
  theme_minimal()

This scatter plot with point size equating to number of attempts shows similar findings to the histogram above in plot 3. In terms of FG percentage (accuracy), long two pointers (10-20 feet) are made only slightly more than three pointers. Teams may prioritize three pointers over long twos because the shooters are almost as accurate, and will get an extra point from the shot.

6. Faceted histogram: shot distance by season

The same distribution as plot 3, split by season, shows how the shot profile changes over time.

Code 
shots |>
  filter(shot_dist <= 40) |>
  ggplot(aes(x = shot_dist, fill = shot_value)) +
  geom_histogram(binwidth = 1, boundary = 0, color = "white", linewidth = 0.1) +
  facet_wrap(~ season, ncol = 2) +
  scale_y_continuous(labels = comma) +
  scale_fill_manual(values = c("2-pt" = "darkblue", "3-pt" = "red")) +
  labs(
    title = "Distribution of Shot Distance, Faceted by Season",
    subtitle = "Shots from 40 ft or closer",
    x = "Shot distance (ft)",
    y = "Attempts",
    fill = "Shot value"
  ) +
  theme_minimal() +
  theme(legend.position = "bottom")

These faceted histograms show some interesting results. Over the years of this data, the long two (~15 to 20 feet) has essentially been eradicated. In the first histogram (2015), there is a small hump before the three point line, suggesting there were still a group of specialized shooters going for long range twos. Compare this to 2019, and this hump has been smoothed down, suggesting these mid-range shooters have shifted to shooting three pointers more, and long two pointers less.

7. Heatmap: 3-point attempt rate by team and season

A plot type where each tile is the share of a team’s attempts that were threes in that season.

Code 
three_rate <- shots |>
  group_by(shooting_team, season) |>
  summarise(three_rate = mean(shot_value == "3-pt"), .groups = "drop") |>
  mutate(shooting_team = fct_reorder(shooting_team, three_rate))

ggplot(three_rate, aes(x = season, y = shooting_team, fill = three_rate)) +
  geom_tile(color = "white") +
  geom_text(aes(label = percent(three_rate, accuracy = 1)), size = 2.8) +
  scale_fill_gradient(low = "lightgrey", high = "red", labels = percent) +
  labs(
    title = "Share of Field-Goal Attempts that were 3-Pointers",
    subtitle = "Teams ordered by their average 3-point rate",
    x = "Season",
    y = "Team",
    fill = "3PA rate"
  ) +
  theme_minimal() +
  theme(panel.grid = element_blank())

Here is a breakdown of all 30 NBA teams in this data coded by how many of their shot attempts were behind the three point line, by year. We can see almost every team gradually adapted to taking more threes from 2015 to 2020. From 2017 to 2020, the Houston Rockets took three point attempts for over 50% of their total shots!

Side tangent but at this time Houston revolutionized their offense around taking as many three point attempts as possible, centered around their prolific shooter James Harden. Many other teams followed this strategy, although not to this extreme level, with three point specialists like Steph Curry (GSW), Damian Lillard (POR), and Luka Doncic (DAL) to name a few.
